# Схема участка — оцифровка

Интерактивный план по рукописному эскизу: все зоны подписаны, размеры взяты с чертежа.

## Открыть

Откройте [`index.html`](./index.html) в браузере.

Исходный эскиз: [`original-sketch.jpg`](./original-sketch.jpg).

## Элементы с размерами

| Элемент | Размер |
|---------|--------|
| Футбольное поле | 9×14 м |
| Теннис + воркаут + баскетбол | 9×8 м |
| Баня | 3×4 м |
| Костёр | 5×5 м |
| Мангал | 3×4 м |
| Бытовка | 2,5×6 м |

## Прочие зоны

Дом, теплица, горка зимняя, ель новогодняя, качели, газон, парковка/клумбы, дорожки, габион, канава, деревья по периметру. Маркеры **К** / **С** — коммуникации у въезда.

Габарит участка (~25×42 м) оценён по пропорциям эскиза — на чертеже не подписан.
