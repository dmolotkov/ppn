# Семейный футбол — план на 2 недели

Домашние тренировки для троих детей (**6 / 9 / 11 лет**):  
3 раза в неделю × 25–30 минут. Все упражнения идут одной лентой, у каждого — визуальная схема.

## Скачать один PDF

**[`Vse_trenirovki_2_nedeli.pdf`](./Vse_trenirovki_2_nedeli.pdf)** — весь план в одном файле  
(обложка + тренировки 1–6 + цели). Сохраните на телефон и открывайте офлайн.

Прямая ссылка на скачивание (не просмотр в браузере):  
https://github.com/dmolotkov/ppn/raw/cursor/football-training-pdf-5dd1/Vse_trenirovki_2_nedeli.pdf

То же содержимое: [`family_football_2weeks.pdf`](./family_football_2weeks.pdf).  
Отдельные тренировки — в [`trainings/`](./trainings/).

## Пересобрать

```bash
pip install -r requirements.txt
python3 generate_training_pdf.py
```

Нужен шрифт DejaVu Sans (`/usr/share/fonts/truetype/dejavu/`).
